QGIS Geometry Checker rules

Rule-024 through Rule-040 add all checks requiring only one input layer. Node checks run on safe normalized 2D geometry; relationship overlays require valid geometries. Short ring evidence can produce a Rule-027 event while the core record remains parse_failed. GEOS validity and additional simplicity constraints are independent.

Precision is applied to working GEOS coordinates for the relevant QGIS checks. Original inputs are not repaired or reprojected. Multiple events per feature, feature pair or line-part pair retain distinct source paths. Independent PyQGIS algorithm comparisons record their actual versions; they do not establish GUI plugin error-row parity.
