Single-layer rule boundaries

New checks require planar 2D supported geometries. GeometryCollections are not expanded. Cross-layer checks, automatic fixes, reprojection and arbitrary QGIS Processing algorithms are outside this build. Thresholds use original coordinate units, not implicit metres.

Different plugin variants are separate rules: Rule-014 counts exactly shared endpoints, while Rule-030 follows Geometry Checker line-connection semantics. Rule-013 forbids multiple parts, while Rule-029 requires a Multi geometry to contain more than one part. Rule-035 groups preceding duplicate members rather than reporting every unordered pair.

Checks retain fixed resource and time budgets. Excluded, failed, cancelled or incomplete work is never presented as completed coverage. Historical algorithm comparison used QGIS 3.40.3 with GEOS 3.13.0; QGIS 3.44 GUI plugin parity remains a separate acceptance step.
